## 1. 输入来源选择

按以下顺序选择正文来源：用户提供的最终出版 PDF或本地全文 → 出版社/会议正式页面 → DOI、arXiv 或机构仓储中的完整版本 → 作者公开稿。搜索摘要或二手介绍只能用于定位原文，不能代替正文证据。

- **本地文本型 PDF**：直接提取目录和正文，并抽查页码、表格、公式是否错位。
- **网页或 DOI**：先确认页面对应的版本、标题、作者和年份，再打开全文或下载 PDF。
- **扫描 PDF**：先 OCR，再抽查首页、目录、关键数字和表格。OCR 不可靠的字段标记为未核验。
- **多个版本**：优先正式出版版；若方法或页码与预印本不同，在内部证据记录中标明版本。
- **付费墙或登录限制**：不绕过访问控制。请求用户提供合法可访问全文，或把工作范围降为摘要级。

## 2. 最小证据集

全文级阅读笔记至少需要：

- 首页或正式出版页，用于题目、作者、类型、来源与链接；
- 真实目录或章节标题，用于论文结构；
- 引言或问题陈述，用于研究问题；
- 方法章节，用于研究方法与创新；
- 实验/分析和结论，用于结果与不足；
- 表、图或正文中的原始数字位置，用于所有定量结论。

若缺少其中一项，只留空受影响字段或明确降级范围。不得用一般领域知识填补论文专属事实。

## 3. 资源受限模式

低算力或大论文时按三遍法处理，避免一次把全文装入上下文：

1. **地图遍**：只读首页、目录、摘要和结论，建立章节地图与文献类型。
2. **目标遍**：按字段分别读取引言、方法、实验/分析和相关附录，记录证据位置。
3. **核验遍**：只回查写入笔记的数字、名称、创新和不足，不重复全文总结。

优先使用文本搜索定位算法名、数据集、`limitation`、`future work`、表号和图号。对长表只提取与研究问题相关的列，不把整张表复制进上下文。

## 4. 异常决策表

| 情况 | 动作 | 最终状态 |
| --- | --- | --- |
| 只有摘要 | 只生成摘要级内容并明确范围；不得写详细方法、实验或不足 | degraded |
| PDF 无文本层 | OCR 并抽查；关键数字无法确认时留空 | degraded / blocked |
| 原文与出版页元数据冲突 | 采用正式出版页，并在证据记录中说明版本差异 | ready |
| 论文没有原创实验 | 使用综述/理论论文结果写法，不写“本文实验” | ready |
| 作者未声明不足 | 仅在实验退化、计算开销或未覆盖场景有明确证据时写；否则省略 | ready |
| 模板缺失或哈希不符 | 停止，恢复锁定模板；禁止重建 | blocked |
| 缺少 `python-docx` | 切换到能导入该包的 Python；仍不可用则安装依赖或停止 | blocked |
| 没有 Word/LibreOffice | 尝试已安装的文档渲染工作流；否则只完成结构审计并报告视觉 QA 未完成 | degraded |
| 输出路径等于模板或已存在 | 更换输出路径；用户明确授权覆盖时才加 `--force` | ready |
| 旧 JSON 的创新/不足分组含糊 | 改为 `innovations` 与 `limitations`；不要猜测 | blocked |

## 5. 临时文件与隐私

把 JSON、OCR 文本、证据表、PDF 和页面图片放在任务专用临时目录。最终 DOCX 通过后删除临时产物；不要删除用户提供的论文。若论文含未公开或敏感内容，不上传到未获授权的外部服务，不在最终笔记中加入原文未要求的个人信息。

任务 JSON 不得包含 API 密钥、Cookie、访问令牌或账号密码；访问论文所需的认证信息只保留在浏览器会话、系统密钥存储或环境变量中。日志和交付说明只记录变量名，不记录值。交付前用 `scripts/audit_skill_security.py` 扫描 skill 根目录和任务专用目录；发现或警告未清零前停止交付。
