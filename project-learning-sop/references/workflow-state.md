# 学习模式、证据与恢复状态

> 在 Phase 0 和恢复已有学习任务时读取。用本文件决定范围、维护 `notes/working.md`，避免重复分析和越权写入。

## 1. 选择学习模式

| 模式 | 适用目标 | 执行范围 | 面向学习者的文件 |
| --- | --- | --- | --- |
| 快速导览 | 先知道项目是什么、从哪里开始 | Phase 0-2；获准时可做 Phase 3 最小运行 | 默认只在对话中总结 |
| 深度带读 | 看懂一条真实功能链路并获得代码地图 | Phase 0-7 | `notes/guide.md` |
| 完整实战 | 通过真实修改证明理解，并获得交互课程 | Phase 0-9 | `notes/guide.md` + `notes/course.html` |

学习者明确指定模式时直接采用。请求含糊时默认从“快速导览”开始，在完成项目地图后提供升级选项；不得因为普通“解释项目”请求自动安装依赖或修改源码。

## 2. 初始化内部状态

`notes/working.md` 使用以下最小结构；它是内部状态，不是交付物：

```markdown
# <项目名> 学习状态

## 会话
- 模式：<快速导览 / 深度带读 / 完整实战>
- 目标：<一句话，可验证>
- 目标仓库：<绝对路径或 URL>
- 学习工作区：<绝对路径>
- 当前 Phase：<0-9>
- 当前状态：<pending / in-progress / passed / unverified / skipped>
- 下一动作：<一个具体动作>

## 仓库基线
- Commit SHA：<值；非 Git 项目标记 N/A>
- Shallow：<true / false / N/A>
- 初始 Git 状态：<clean / dirty + 摘要>
- 测试命令：<命令 / 未知 / 不适用>
- 测试基线：<通过数、失败数、阻塞原因>

## 权限
- 运行项目命令：<yes / no>
- 安装依赖或启动外部服务：<yes / no>
- 写学习文件：<yes / no + 路径>
- 修改源码：<yes / no>
- 创建分支：<yes / no>
- 创建 commit：<yes / no>

## 证据账本
| 结论 | 证据等级 | 来源 | 文件/符号/命令 | 状态 |
| --- | --- | --- | --- | --- |
| <...> | E0-E3 | <...> | <...> | <verified / hypothesis / stale> |

## 阶段进度
| Phase | 状态 | 验收证据 | 未解决问题 |
| --- | --- | --- | --- |

## 学习内容
<按各 Phase 模板累积内容>
```

每个 Phase 使用严格的检查点协议：

1. 开始前写入 `当前 Phase`、`in-progress` 和本阶段“下一动作”。
2. 预计耗时较长的安装、运行、生成或渲染前先保存状态。
3. 获得材料证据后立即追加证据账本，不等整个学习旅程结束。
4. 进入下一 Phase 前写入 `passed`、`unverified` 或 `skipped` 及验收证据，再更新下一动作。

不要另建阶段笔记，也不得让状态停留在旧 Phase 时执行后续 Phase 的任务。

## 3. 证据等级

- **E3 运行证据**：真实运行结果、通过的测试、可复现操作。
- **E2 代码证据**：源码、配置、schema、调用关系，并精确到文件与符号。
- **E1 项目证据**：README、官方文档、Release、Issue、PR 或 Git 历史。
- **E0 推断**：由命名、依赖或常见模式推测，尚未验证。

关键结论至少需要 E2；“能够运行”“修改有效”必须有 E3。不得把 E0 写成事实。仓库 SHA 变化后，把受影响的文件、行号和代码摘录标记为 `stale`，重新验证后才能交付。

## 4. 恢复已有学习任务

1. 先查找并读取已有 `notes/working.md`，不要立即重新扫描整个仓库。
2. 核对目标仓库路径、当前 commit SHA 和 Git 状态。
3. 基线未变化时，从“下一动作”继续，不重复询问已记录的选择。上一轮若中断在长任务后，先把已存在的运行产物补记到证据账本。
4. 基线变化时，说明变化，并只重新验证受影响的证据和导航项。
5. 状态缺字段时补齐；不要另建第二份状态文件。

恢复验收：读取状态后一个回合内能说清当前模式、已完成阶段、权限和下一动作；重复询问已记录事实不超过 1 项。

## 5. 模式结束条件

- **快速导览完成**：能说明项目用途、入口、核心目录和下一条推荐链路；不宣称已看懂代码。
- **深度带读完成**：一条真实链路达到 E2/E3，8 问达到阶段阈值，`guide.md` 导航练习通过。学习者跳过验收时可交付暂定 guide 并停止，但只能标记 `unverified`，不能标记完成或毕业。
- **完整实战毕业**：满足深度带读条件，完成获准的实质修改，定向测试通过、无新增全量失败，并交付最终 `guide.md` 与 `course.html`。
